# Consuming-project knowledge

This directory is an empty documented skeleton for the project that adopts the template. Its
contents are project-owned, may be private, and must never be overwritten or promoted by future
automatic core synchronization.

- [[vault/project/research/README|Research]]

- `vault/project/inbox/` — default location for uncategorized new notes
- `vault/project/attachments/` — ignored local attachments; do not commit by default

Keep machine-ranking evidence in [[memory/README|memory]] separately. The curated vault preserves
human context; it does not replace the loop's compact feedback substrate.
