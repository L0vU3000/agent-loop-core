# Core decisions

Store detailed, load-bearing decisions about the reusable core here with
[[vault/templates/decision]]. Use lowercase kebab-case filenames. Include alternatives,
consequences, and a concrete revisit condition.

If the choice should influence `pipeline-improve`, add a concise entry to [[memory/decisions]] and
link back to the detailed note. Consuming-project decisions belong under
[[vault/project/decisions/README]].
